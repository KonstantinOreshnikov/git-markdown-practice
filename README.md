# Engineering Learning Path / Инженерный учебный маршрут

A bilingual map of practical learning repositories covering collaboration, programming, quality engineering and automation.

Двуязычная карта практических учебных репозиториев по совместной разработке, программированию, quality engineering и автоматизации.

## English

The original learning archive contained many small repositories, lesson cards and attachments. This map turns that history into four coherent tracks. It links to original, anonymized documentation and code; private course files and organization-specific information are deliberately excluded.

## Русский

Исходный учебный архив состоял из множества небольших репозиториев, карточек уроков и вложений. Эта карта объединяет историю в четыре последовательных трека. Здесь размещаются ссылки на оригинальную обезличенную документацию и код; приватные файлы курсов и информация организаций намеренно исключены.

## Recommended order / Рекомендуемый порядок

1. Git mental model and branch workflow.
2. Python foundations, files, errors and tests.
3. Test analysis, API contracts and web automation.
4. Linux automation, SSH, containers and CI.
5. Build one small capstone that uses all four tracks.

---

1. Модель Git и работа с ветками.
2. Основы Python, файлы, ошибки и тесты.
3. Тест-анализ, API-контракты и web automation.
4. Автоматизация Linux, SSH, контейнеры и CI.
5. Один небольшой итоговый проект, объединяющий четыре направления.

## Capstone / Итоговый проект

Build a neutral daily-efficiency tracker: Python scoring core, API tests, a small web flow, automated checks and documented deployment. Use synthetic data only.

Создайте нейтральный трекер ежедневной эффективности: Python-ядро расчёта, API-тесты, небольшой web-flow, автоматические проверки и документированное развёртывание. Используйте только синтетические данные.

## Publication policy / Политика публикации

- Original explanations and code only.
- English first, Russian immediately after.
- Official sources for current practices.
- No employer, customer, account, credential or private-course data.
- Historical repositories remain available until consolidation is verified.
